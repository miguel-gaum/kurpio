# Kurpio

Music. Gaming. Social.

Kurpio is a desktop application designed for gamers, combining
music playback, social features, game detection, and an in-game
music overlay in one application.

## Features

🎵 Music Player
- Local music library
- Playlists
- Synced lyrics
- Album artwork
- Custom video/audio controls

🎮 Gaming
- Automatic game detection
- Gaming music overlay
- Audio ducking
- Game library

💬 Social
- Private messages
- Group conversations
- Friend system
- Profiles
- Presence
- Voice chat

## Built With

- Electron
- Node.js
- JavaScript
- HTML/CSS
- PostgreSQL / Neon
- Cloud storage
- LRCLIB
